# Data Professionals Survey Dashboard

An informative dashboard built with Microsoft Power BI to analyze survey data on data professionals' salaries, programming language preferences, career challenges, and job satisfaction.

## Dashboard Preview

![Data Professionals Survey Dashboard](Dashboard_Screenshot.png)

## Key Insights

- **Demographics:** Respondents' countries and professional backgrounds.
- **Salary Analysis:** Average salaries across different job titles.
- **Programming Languages:** Most popular languages among data professionals.
- **Career Challenges:** Perceived difficulty of entering the data industry.
- **Job Satisfaction:** Respondents' satisfaction with salary and work-life balance.

## Tools & Technologies

- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for calculations and measures

## Project Objective

The objective was to practice data cleaning and transformation in Power Query and develop an informative dashboard that presents survey findings through clear visualizations and key performance indicators (KPIs).

## Project Files

- `Data_Professionals_Survey.pbix` — Power BI dashboard file.
- `Data_Professionals_Survey.csv` — Raw survey dataset.
